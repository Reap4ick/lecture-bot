# Lecture Bot

Локальна браузерна сторінка для запису лекцій: зберігає аудіо, після завершення робить словацьку транскрипцію через Whisper і, якщо встановлений мовний пакет Argos, перекладає live-фрагменти українською.

## Вимоги

- Python 3.10 або новіший
- Windows, macOS або Linux
- мікрофон
- приблизно 2–4 ГБ вільного місця для моделі Whisper і записів
- Chrome/Edge для live-тексту в браузері

## Встановлення

```bash
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements.txt
```

Для перекладу зі словацької на українську встановіть два пакети Argos: словацька → англійська та англійська → українська:

```bash
python -c "import argostranslate.package as p; p.update_package_index(); pkgs=[x for x in p.get_available_packages() if (x.from_code,x.to_code) in {('sk','en'),('en','uk')}]; print([(x.from_code,x.to_code) for x in pkgs]); [p.install_from_path(x.download()) for x in pkgs]"
```

Застосунок спочатку шукає прямий маршрут `sk → uk`, а якщо його немає — автоматично використовує `sk → en → uk`. Якщо команда не знайде один із пакетів, запис і словацька транскрипція все одно працюватимуть; переклад можна виконувати окремо.

## Запуск

```bash
python app.py
```

Відкрийте в браузері: <http://127.0.0.1:5000>

Перший запуск після натискання «Зупинити й обробити» завантажить модель Whisper. Можна вибрати іншу модель через змінну `WHISPER_MODEL`:

```bash
# швидше, але менш точно
WHISPER_MODEL=base python app.py
# точніше, але повільніше
WHISPER_MODEL=medium python app.py
```

На Windows у PowerShell:

```powershell
$env:WHISPER_MODEL="base"; python app.py
```

## Що виходить на виході

У папці `data/<session-id>/` зберігаються `lecture.webm`, `transcript_sk.txt`, `transcript_uk.txt` і `transcript_sk.json` з таймкодами. У сторінці є кнопки завантаження.

## Важливі обмеження

- Browser SpeechRecognition для live-тексту залежить від Chrome/Edge і може використовувати онлайн-розпізнавання. Фінальна транскрипція Whisper виконується локально.
- Аудіо завантажується одним WebM-файлом після натискання «Зупинити й обробити». Це зроблено навмисно: склеювання незалежних WebM-фрагментів часто ламає обробку Whisper.
- Фінальна транскрипція запускається після завершення запису, а не постійно наживо.
- Після фінальної транскрипції програма перекладає весь словацький текст через Argos-маршрут `sk → uk` або `sk → en → uk`; він може бути повільним і менш точним за хмарні сервіси.
- Для багатогодинних записів потрібен достатній вільний диск. Не видаляйте папку `data` до завантаження файлів.
- Перед записом отримайте згоду викладача та перевірте правила університету.
